# 质量检查清单

> AI 做完 PPT 后必须逐项检查，P0 不过就打回重做。

---

## P0 — 必须全过（不过就重做）

- [ ] 导航系统正常工作（键盘←→ / 底部圆点 / 左右箭头 / 滚轮）
- [ ] 所有页面的入场动画正确触发（切换页面时元素依次出现）
- [ ] **零 emoji**，全部使用 SVG 线条图标
- [ ] 图标统一 `stroke-linecap:round; stroke-linejoin:round; fill:none`
- [ ] 无 HTML 默认样式（无默认 ul/ol 黑点、无默认 table 边框）
- [ ] 连续两页布局不重复
- [ ] 深色页导航点/页码自动切换为浅色
- [ ] 配色严格使用选定主题的预设值，不自创颜色
- [ ] 每页最多 3 个核心信息点
- [ ] 数据页有明确的结论/洞察文字
- [ ] **无卡片布局(B/D/M/N/O/P)占比 ≥ 40%** — 不能全是卡片
- [ ] **截图发到群里，不会被人说「又是AI做的」** — 最高优先级判断标准

## P1 — 应该过（影响品质）

- [ ] 每个可交互元素都有 hover 效果（卡片上浮、按钮变色等）
- [ ] 入场动画有逐级延迟（delay-1 到 delay-6）
- [ ] 深色/浅色页面交替，不连续超过 2 页同色调
- [ ] 装饰图标有 float-anim 或 pulse-anim
- [ ] 字号对比明显（标题 ≥ 2rem，正文 ≤ 0.95rem）
- [ ] 表格有交替行背景色
- [ ] 流程图节点不超过 7 个
- [ ] KPI数字使用 Playfair Display 衬线体
- [ ] **[数据报告] 原文表格保留了完整列数和行数，未删减**
- [ ] **[数据报告] 关键数据带上下文（同比/来源/趋势方向标注）**
- [ ] **[数据报告] 长段落已拆分为要点列表，但内容未减少**

## P2 — 加分项（锦上添花）

- [ ] 存在至少一个"惊喜"页面（全屏大字/数据大字报）
- [ ] 色块内图标带浮动动画
- [ ] 底部高亮栏（3项核心亮点总结）
- [ ] 标签 hover 有颜色过渡
- [ ] 数据卡片有微妙的边框或阴影变化
- [ ] 时间轴节点有脉冲光晕动画
